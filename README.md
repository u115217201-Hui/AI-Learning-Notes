# AI Learning Notes｜人工智慧學習筆記

可在 GitHub Pages 直接部署的繁體中文 AI 教學網站。第一版包含 **CNN、Transformer、RAG** 三篇獨立教學頁，使用統一版型與原創 SVG 流程圖。

## 使用方式
1. 將整個專案結構上傳到 GitHub Repository 的根目錄。
2. 在 **Settings → Pages** 選擇 **Deploy from a branch**，指定 `main` 與 `/ (root)`。
3. 部署完成後，開啟 `https://<username>.github.io/<repository>/`。

本地亦可直接開啟 `index.html` 瀏覽，網站不需要後端、API Key 或建置工具。
